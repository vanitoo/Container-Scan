# PDF Text Recognition Tool

![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)
![OpenCV](https://img.shields.io/badge/OpenCV-4.5+-green.svg)
![Tesseract](https://img.shields.io/badge/Tesseract-OCR-yellowgreen)


Инструмент для автоматического распознавания текста из PDF-файлов с поддержкой нескольких OCR-движков и возможностью сравнения с эталонными данными.

## 📌 Возможности

- Распознавание текста из PDF с выделением областей
- Поддержка движков OCR:
  - Tesseract (обязательный)
  - EasyOCR (опционально)
  - PaddleOCR (опционально)
- Сравнение с эталонными данными из XLS/CSV
- Режим отладки с сохранением промежуточных результатов
- Гибкая настройка координат распознавания

## 🛠 Установка

### Обязательные зависимости
```bash
pip install -r requirements.txt
```

## Дополнительные движки OCR
```bash
# Для EasyOCR:
pip install easyocr

# Для PaddleOCR:
pip install paddleocr paddlepaddle
```

Установка Tesseract
Windows: Скачать установщик

Linux: sudo apt install tesseract-ocr

🖥 Использование
1. Запустите программу:
```bash
python main.py
```

Интерфейс:

Верхняя панель:

Выбор PDF и файла-реестра

Запуск распознавания

Сохранение результатов

Навигация:

Кнопки перехода по страницам

Выделение области для распознавания

Тестирование области

Настройки:

Выбор OCR-движка

Режимы: "Расширенный" и "Debug"

Поля для шаблона и координат

📂 Сохранение результатов
Включите режим Debug для сохранения:

Полных изображений страниц (_full.jpg)

Областей распознавания (_cropped.jpg)

Текстовых логов с результатами (_info.txt)

🚀 Особенности реализации
Многопоточная обработка

Поддержка двойного клика для перехода к странице

Цветовая маркировка совпадений:

🟢 100% совпадение

🟡 Частичное совпадение

🔴 Нет совпадения

⚠️ Ограничения
Работает только с PDF-документами

Оптимальные результаты для текста на белом фоне

Требует точной настройки координат для сложных документов
